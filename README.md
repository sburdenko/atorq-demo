# Atorq — playable demo

**▶ https://sburdenko.github.io/atorq-demo**

A physics puzzle: slide household objects across a table so they come to rest on pads matching
their shape. When the throws run out the table drops away — whatever is standing on a pad is
saved, everything else falls.

Press **on an item**, drag **back towards yourself**, release. The dotted arrow shows direction
and charge; it is deliberately shorter than the real slide, so judging distance is still on you.

| | Shape | Full credit on |
|---|---|---|
| ● | circle | round pad |
| ■ | square | square pad |
| ▲ | triangle | triangular pad |

Landing on a pad of the wrong shape still scores, but less. The **ON TARGET** counter is live and
can go *down* — a later throw can knock an item off a pad it was already sitting on.

Runs in desktop and mobile browsers, no install.
